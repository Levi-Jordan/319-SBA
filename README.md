A basic database system that keeps track of cardio, weightlifting, and nutrition.

To access routes:

Create and Read 
/api/cardio | cardioRoutes; 
/api/nutrition | nutritionRoutes;
/api/weights | weightsRoutes;

Update and Delete
/api/cardio/:id | cardioRoutes; 
/api/nutrition/:id | nutritionRoutes;
/api/weights/:id | weightsRoutes;
